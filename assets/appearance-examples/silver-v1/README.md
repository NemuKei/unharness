# 白銀 · appearance v1

An original Unharness character co-created with image generation.
The source sheet is entity-poses.png; the three normalized entity PNGs are
produced by src/appearances/entity-poses.mjs at one shared scale.
The bundled hardware remains hangar-layered-v1. artwork.json is a readonly
preview definition; an owned collection item is created only by normal import/save.

The source and derived PNGs contain no company logo. Awakening light crests,
palette emission and bounded motion are rendered locally by entity-awakening/v1.
Appearance selection does not select a model or change a harness.
