# Original AI appearance example

An original adult female AI character generated with the built-in ImageGen
on 2026-09-11 for the Unharness introduction page. The figure demonstrates
custom appearance; it is not a real person's portrait or a performance claim.

`entity-source.png` is the unchanged generated transparent PNG. `entity.png`
is its 724-square import produced by the existing `normalizeLayerPng` path.
`artwork.json` replaces only the stock entity and keeps the standard restraints
and background. The website uses the real layered Hangar renderer for all
three mode previews.

Prompt: one full-body adult female AI in authentic Japanese RPG pixel art,
pearl-silver short hair with a lavender underside, cyan eyes, geometric hair
accessory, a fully clothed ivory/graphite utility jacket, dark trousers,
gloves and practical boots, and restrained cyan circuit accents. Calm frontal
pose, transparent square canvas with margins; no text, logo, extra character,
background, floor or restraints. The application supplies the other layers.
