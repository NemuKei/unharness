# モデル別の一次資料

初期設定と設定の見直しで使う。`status`と利用者の指定から実際のモデルを確認し、
同じモデルの公式資料を読む。資料は確認時に取得する。古い参照やモデル名だけから
「現在の推奨」と断定しない。

- **GPT-6 Astra**: [Skillとプロンプトの見直し（2026-09-11）](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)と、選択したモデルに対応する[公式モデルガイド](https://developers.openai.com/api/docs/guides/latest-model)。
- **その他のモデル**: そのモデルとアプリに対応する最新の一次資料を探す。モデル専用の資料がなければ、使った共通資料と不足する情報を示す。Astra向けの助言を他のモデルへ一律に当てはめない。

Astraでは、Skillの適用範囲、必要な時だけ読む構成、過剰な手順の指定、
完了条件と自律的に進められる範囲を見直す。

Unharnessで行うのは、その知見と利用者の仕事を基にした、登録済み対象の
disabled/manual/automaticや限定解除の最小指示の提案。モデル名、出所、
実際に読んだURL・タイトル・確認日時、採用理由を`review_setup`の`basis`へ残す。
記事を読むだけで最適性や性能向上を確認したとは扱わない。

Normal、メモリ、継続設定、権限、管理ルール、必須プロジェクト条件と、
現在のMac版で保持する公式プラグインは引き続き保持する。
Skill本文やNormalを作り替える提案は、モード選択の保存とは別の変更として扱う。
新しいモデルや資料が公開されても、保存済みの設定を自動で書き換えない。
