## 追加確認：零式から通常装備への復帰

- 同じ SHA-256 の実行ファイルを使い、`HOME` と `CODEX_HOME` を一時的な合成ディレクトリに向けた。合成の追加指示・Skill を登録して通常装備を保存した。一時ディレクトリは確認後に削除した。
- `planUserMode(trueform)` → `applyUserPlan` の読み戻しは `matched`。合成 Skill の設定は `enabled = false` になった。続く `planUserMode(normal)` → `applyUserPlan` も `matched`。config とほかの登録対象、計7ファイルの内容は保存前のバイト列と一致した。
- この復帰は `skills/config/write(enabled: true)` を使わず、保存した Normal の内容を guarded transaction で戻す経路である。先に見つかった `enabled: true` RPC の差は残るため、今回確認できたのは `read`・合成 Skill の `disable`・保存済み Normal への復帰だけである。
- 操作別の許可では、0.155.0-alpha.16.3 に `read` と合成 Skill の `disable` だけを加える。Skill の `enable` とプラグイン設定の書き込みは、この確認から許可しない。
- 未確認：Skill を通常装備より上へ有効化する操作、`config/batchWrite`、プラグイン設定、複数 Skill、独立した設定変更を挟む復元、中断からの復旧、Desktop の新規タスクでの読み込み。
